Anonymous usage statistics

Once a day this installation sends a few counts (users, projects, terms, translations, locales and API clients) and two settings, signed with its own key. It never sends a name, an e-mail address, a project, a term, a translation or a key. Turn it off here, or set TR_EVER_STATS_ENABLED=false on the server and restart the API (the setting is read at startup).
